SB01 — Unitree G1 Conversation

A voice-driven conversation system for the Unitree G1 humanoid robot, nicknamed sb01. The robot listens via on-board ASR, reasons with Claude, and speaks back with Edge TTS in real time — with face recognition loading a per-person memory profile at startup. Developed for the CSUSB robotics program.

Overview

Features

  • Voice conversation over DDS with natural speech replies
  • Emotion-aware chest LEDs (happy → yellow, sad → purple, angry → red)
  • Face recognition at startup, loading a persistent per-person memory profile
  • Automatic weather lookups when a weather question is detected
  • Multilingual TTS — auto-detects English vs. Spanish

Hardware

  • Ethernet (eno0) for DDS — ASR in, TTS/LED out
  • WiFi for Claude API + web/weather lookups
  • Unitree SDK2 for DDS communication with the G1
